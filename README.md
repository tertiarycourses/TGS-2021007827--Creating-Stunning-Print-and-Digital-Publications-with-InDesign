## About

Adobe InDesign is the industry-standard page-layout application for print and digital publishing. This one-day WSQ course takes you from establishing a client's drawing and layout requirement, through building the document and using the InDesign toolset, to refining and exporting a production-ready publication for both press and screen.

Every activity is a **realistic Singapore workplace case study** built on a single running client — *Harmony Petals*, a florist with three retail outlets — so you practise the judgement the job needs, not just the clicks.

## Learning Outcomes

- **LO1 · Establish & create** — Establish the drawing layout requirement from a client brief — trim, bleed, margins, columns, colour mode and binding — and create the correctly specified InDesign document with parent pages, grids and guides.
- **LO2 · Utilize InDesign tools** — Utilize the InDesign drawing toolset — text frames and threading, the Pen and shape tools, paths and Pathfinder, colour, gradients, transparency and effects, transform, align and layers — to build the page.
- **LO3 · Refine the drawings** — Refine the layout with professional typography, paragraph/character/object styles, tables, interactivity and a preflighted, correctly packaged export for both print and digital delivery.

## Rebuilding the Courseware

All artifacts are generated from a **single source of truth** so they can never drift apart.

```bash
cd .claude/skills/courseware-build/build

python3 make_graphics.py        # concept diagrams -> courseware/assets/gen/
python3 build_slides.py         # the deck + slide_index.json
python3 build_lesson_plan.py    # the LP (reads slide_index.json)
python3 build_learner_guide.py  # the LG, its Markdown mirror and activities/
```

| File | Role |
|---|---|
| `course_data.py` | Metadata, outcomes, TSC mapping, topics and key concepts |
| `data_domain1..3.py` | The 20 activities — scenario, steps, test, questions |
| `engine.py` | Slide component library (tile grids, process maps, image layouts) |
| `make_graphics.py` | Generates the concept diagrams as PNGs |
| `slide_index.json` | Slide numbers emitted by the deck build, consumed by the LP |
