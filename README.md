## About the course

Adobe InDesign is a page-layout application for print and digital publishing. This course takes learners from defining purpose, audience and production specifications through document setup, pages, text, graphics, colour, typography, styles, tables, interactivity, preflight, packaging and output.

The course uses a connected workplace case study and 20 hands-on labs. The trainer deck focuses on concepts and production judgement; detailed click-by-click procedures live in the Learner Guide and each lab's printable `INSTRUCTIONS.pdf`.

## Learning outcomes

- **LO1 - Establish and create:** Establish the drawing layout requirement from a client brief and create the correctly specified InDesign document with parent pages, grids and guides.
- **LO2 - Use InDesign tools:** Use text frames and threading, graphics and links, Pen and shape tools, paths and Pathfinder, colour, gradients, effects, transform, align and layers.
- **LO3 - Refine the drawings:** Refine the layout with typography, styles, tables, interactivity and a preflighted, correctly packaged export for print and digital delivery.

## Topics covered

1. **Get Started on InDesign** - purpose and audience, rights and accessibility, production specifications, interface, document setup, parent pages, numbering, grids and guides.
2. **Basic InDesign Drawing Techniques** - text and threading, frames and paths, graphics and links, colour, gradients and effects, transform, align and layers.
3. **Refine InDesign Drawings** - typography, styles, tables, interactivity, preflight, packaging, PDF/X, EPUB and online delivery.

## Delivery and assessment

Training runs from 9:30 am to 6:30 pm with a one-hour lunch. The eight instructional hours include demonstrations, guided practice, labs, review and required digital attendance activities.

The approved assessment model is:

- Practical Performance (PP): 75 minutes, open book, assessing A1-A4.
- Oral Questioning (OQ): 15 minutes, one-to-one, open book, assessing K1-K3.

## Prerequisites

- Able to operate a computer confidently; minimum three GCE O-Level passes including English, or WPL Level 5.
- Minimum one year of working experience.
- Adobe InDesign 2024 or later on Windows or macOS.
- A laptop and mouse; 1280 x 800 or larger display recommended.
- Lab package downloaded from the LMS before class.

## Public/private distribution boundary

This public repository contains learner-facing courseware and labs only. It deliberately excludes assessments, answer keys, trainer reference sources, credentials, archives, QA renders and private build/release tooling. Approved trainers receive controlled assessment materials through the authorised Google Drive workflow; answer keys are never linked from the LMS or published here.

Large InDesign and media binaries are stored with Git LFS. Clone with Git LFS enabled to receive the actual learner files instead of pointer files.
