# Lab 19 - Preflight, Package and Export a Print-Ready PDF/X

**Topic 03: Refine InDesign Drawings** | **LO3** | TGS-2021007827 | v13.0

Use InDesign's live Preflight to define and run a production profile, resolve every error in the Links panel, clear overset text, then package the job with fonts and links and export a PDF/X-1a file carrying 3 mm bleed and crop marks — the exact deliverable a commercial litho printer expects.

## Start Here

1. Read [`INSTRUCTIONS.pdf`](INSTRUCTIONS.pdf) or the editable [`INSTRUCTIONS.md`](INSTRUCTIONS.md).
2. Duplicate `travel_magazine_tutorial.indd` as `Lab-19-Working.indd`.
3. Keep every supporting asset in this folder so links remain portable.
4. Use [`CHECKLIST.pdf`](CHECKLIST.pdf) before submitting your evidence.
