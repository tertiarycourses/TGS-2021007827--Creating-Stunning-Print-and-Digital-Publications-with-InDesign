# Lab 17 - Add Hyperlinks, Buttons and QR Codes for an Interactive Document

**Topic 03: Refine InDesign Drawings** | **LO3** | TGS-2021007827 | v13.0

Turn a static catalogue into a working interactive document: create and manage URL and cross-reference hyperlinks with shared destinations, convert an object into a button with a rollover appearance and a Go To URL action, and generate a live vector QR code directly in InDesign. You then test everything before export.

## Start Here

1. Read [`INSTRUCTIONS.pdf`](INSTRUCTIONS.pdf) or the editable [`INSTRUCTIONS.md`](INSTRUCTIONS.md).
2. Duplicate `HP_InteractiveDoc_A.indd` as `Lab-17-Working.indd`.
3. Keep every supporting asset in this folder so links remain portable.
4. Use [`CHECKLIST.pdf`](CHECKLIST.pdf) before submitting your evidence.
