# Lab 2 - Create the Document and Explore the InDesign Workspace

**Topic 01: Get Started on InDesign** | **LO1** | TGS-2021007827 | v13.0

Create the flyer document from the signed-off specification, learn the Start workspace and the New Document dialog including presets and Adobe Stock templates, then build and save a custom workspace containing the panels a layout designer actually uses.

## Start Here

1. Read [`INSTRUCTIONS.pdf`](INSTRUCTIONS.pdf) or the editable [`INSTRUCTIONS.md`](INSTRUCTIONS.md).
2. Duplicate `parent-pages.indd` as `Lab-02-Working.indd`.
3. Keep every supporting asset in this folder so links remain portable.
4. Use [`CHECKLIST.pdf`](CHECKLIST.pdf) before submitting your evidence.

Harmony_Flyer.indd — an A5 landscape, 2-page, CMYK document with 3 mm bleed and 5 mm margins, plus a saved custom workspace named 'Publication Layout'.

Save the final native file as `Lab-02-Completed.indd`.
