# Lab 4 - Set Up Grids, Guides and a Modular Column Structure

**Topic 01: Get Started on InDesign** | **LO1** | TGS-2021007827 | v13.0

Diagnose why an unaligned page reads as untidy, then build the invisible skeleton that fixes it: a baseline grid for the type, a document grid for objects, ruler guides for specific positions, and a full modular grid created in one dialog with Layout > Create Guides.
